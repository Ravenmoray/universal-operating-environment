# Contributing

UOE is in the public research and architecture phase. Contributors are welcome to challenge assumptions, write RFCs, submit test fixtures, document compatibility behavior and contribute code.

- Discuss substantial architecture changes in an issue or RFC before implementation.
- Include tests, evidence and documentation for functional changes.
- Treat binaries, model outputs and external data as untrusted.
- Only contribute material you have the right to distribute under its stated license.
- Do not upload secrets, personal data, proprietary binaries or training corpora without explicit redistribution rights.
- Include third-party notices and verify license compatibility.

## Licensing contributions

Unless explicitly agreed otherwise before contribution, contributions are provided under the repository's **AGPL-3.0-or-later** license. You retain your copyright. Existing third-party software retains its original terms; please identify reused code and its license clearly.

Contributing does not imply endorsement of every long-range goal.
